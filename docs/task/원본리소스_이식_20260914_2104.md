# Task: 원본 리소스 이식

## Purpose

원본 WOT(`../WOT/WOT`, Develop 브랜치)의 리소스를 정리해서 git으로 데이터를 보관하고, 이 저장소에서 참조할 수 있게 한다.
리소스는 공개되지 않아야 한다 — 이 저장소는 공개 포트폴리오이고 리소스 출처·팀원 동의가 확인되지 않았다.
지금 이 저장소에는 실제 게임 리소스가 없고, `tests/fixtures/textures/intro_logo.png`(4x4 placeholder) 같은 임시 파일만 있다.
이후 씬 이식 사이클(보류 중인 `타이틀씬_이식` 포함)이 placeholder 대신 실제 리소스를 쓰려면, 리소스가 먼저 이 저장소 안에 정리된 형태로 버전 관리되어야 한다.

## 현황 (문제 정의용 사실 기록)

원본 리소스 구성은 2026-09-14 기준 다음과 같다.

| 폴더 | 파일 수 / 용량 | 형식 | 지금 프로젝트에서 읽을 수 있는지 |
|---|---|---|---|
| `Textures/UI` | 44개 / 37MB | .png | 가능 (graphics `LoadTexture`) |
| `Textures/Model`, `Landscape`, `WOT_FX`, `Trail` | 115개 / 215MB | .png, .dds | png 가능, dds 미확인 |
| `Sound` | 32개 / 19MB | .mp3, .ogg, .wav, .flac, .ini | 불가 (오디오 서브시스템 없음) |
| `Models/Meshes`, `Materials` | 133개 / 10MB | .mesh, .mat, .mats (원본 엔진 전용 형식) | 불가 (임포터는 OBJ/FBX/GLTF/GLB만 지원) |
| `Models/LandscapeMaps`, `TextData` | 41개 | .map, .png, .csv, .srt | 불가 (파서 없음) |

- 전체 합계는 약 280MB이며, 가장 큰 파일은 `Textures/Landscape/skyBox.dds`(32MB)다.
- 원본 저장소에 커밋되지 않은 변경(`WOT/TextData/Transforms/MainCamera.srt`)이 있다.
- 저장소 공개 여부(2026-09-14, 비로그인 GitHub API 조회): 원본 `kjejhk37/WOT`는 조회되지 않음(비공개로 추정), 이 저장소 `kjejhk37/World-of-Tank-imitation-Refactoring`는 공개.
- 따라서 지금 리소스는 비공개 저장소에만 있고, 이 저장소에 커밋하면 처음으로 공개 배포되는 상황이다.
- 원본 저장소 git 기록상 `Textures`/`Sound` 파일은 2023-01-06 ~ 2023-01-15에 사용자가 아닌 다른 팀원 계정들이 추가했다(버튼·배경·로딩 이미지, 배경음악, 차고 모델, 홀로그램 텍스처 등). 원본 WOT는 팀 프로젝트였다.
- 원본 저장소 안에 리소스 출처·라이선스를 적은 파일(license/readme/credit)은 없다.

## 요약

- 원본 WOT 리소스 전체(약 280MB, 텍스처·사운드·모델·데이터)를 정리해 git으로 버전 관리하는 것이 목적이다.
- 리소스는 비공개 git 저장소에 두고, 공개 코드 저장소(이 저장소)가 그 비공개 저장소를 submodule로 참조한다. 권한이 없는 사람은 리소스를 받을 수 없다.
- 리소스 중 일부 형식(.mesh/.mat/.srt/.map/.ogg/.wav)은 지금 프로젝트가 읽을 수 없지만, 목적이 보관이므로 범위에 포함한다.
- 리소스 출처(저작권)와 팀원 동의는 아직 확인되지 않았지만, 비공개 보관이라 공개 배포에 해당하지 않으므로 이번 사이클 진행을 막지 않는다. 비공개 저장소를 공개로 바꾸기 전에는 반드시 확인해야 한다.
- 기준 버전은 원본 Develop 브랜치 마지막 커밋 `3b497a3`이다.
- Task 문서는 확정되었고 남은 확인 사항은 없다 — Step 2(브레인스토밍)로 진행한다.
