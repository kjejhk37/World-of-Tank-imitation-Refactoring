# Task: 기초 빌드 구조 및 진입점 확보

## Purpose

`World-of-Tank-imitation-Refactoring` 내에 기초적인 빌드 구조를 만들고, 진입점(entry point)을 확보한다.

개발은 `World-of-Tank-imitation-Refactoring` 디렉토리 내에서만 진행한다.
`WOT-master`는 참고용 원본 코드베이스로만 사용한다.

(비워둠)

## User Draft

- 원본 `D3DX_2209.cpp`의 진입점은 `int APIENTRY wWinMain(...)`이며, 콘솔 `int main()`이 아니다.
- 빌드 시스템은 CMake, 에디터는 VS Code를 사용한다.
- 지금은 "기초적인 빌드 구조" 단계이며, 구현 범위(순수 스텁 / 빈 창 생성 / DirectX 디바이스 초기화까지)와 디렉토리 구조는 아직 정해지지 않음 — 브레인스토밍에서 논의 필요.

- 현재 WOT-master 와 다르게 World-of-Tank-imitation-Refactoring 에서는 진입점으로 int main() 으로진행
  -> 이유 : 추 후 DirectX 뿐 아니라 Open GL 사용을 고려
