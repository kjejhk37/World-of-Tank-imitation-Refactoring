실행 시점에 전달되는 인자를 기준으로 어떤 렌더링 백엔드를 사용할지 진입점을 결정할 수 있는 구조를 확보한다.

## User Draft

- DirectX와 OpenGL은 기본 설정(초기화 방식)이 서로 다르므로, `main.cpp` 안에서 두 경로를 나눠서 진행하고 싶음.
- 목적은 인자를 사용해서 주요 진입점(어느 렌더링 백엔드를 쓸지)을 바꾸는 것.
- 사용자가 언급한 표현은 `*args`/`**kwargs`(Python 문법)이며, C++에는 동일한 개념이 존재하지 않음.
  → 브레인스토밍에서 C++ 관점의 대응 방식(예: `argc`/`argv` 명령줄 인자 파싱, 설정 구조체, 팩토리 패턴 등) 논의 필요.
- 현재 `main.cpp`는 순수 스텁(`int main() { return 0; }`) 상태이며, DirectX/OpenGL 초기화 로직은 아직 없음.
