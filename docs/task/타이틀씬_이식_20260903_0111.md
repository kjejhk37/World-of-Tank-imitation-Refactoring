## 요약

- 원래 목적은 원본 TitleScene(배경·로고·버튼·튜토리얼 텍스트) 이식이었다.
- 브레인스토밍에서 목적이 "여러 씬을 전환하는 매커니즘 정비 + TitleScene/LoadingScene 최소 스텁"으로 재정의되었다.
- 원본 TitleScene의 실제 콘텐츠(로고 페이드인, 튜토리얼 페이지, 종료 확인 페이지, 배경음악)는 이번 사이클에서 제외되었다.

## 사용자 결정 사항

1. 이번 사이클의 목적을 "TitleScene 이식"에서 "씬 전환 매커니즘 정비 + TitleScene/LoadingScene 최소 스텁"으로 재정의했다.
   → 전략서 체크리스트가 SceneManager 싱글턴 전환, GameManager 삭제, 스냅샷 대상 씬 선택, 스텁 씬 전환 검증 중심으로 구성된다.
2. 사운드(`Audio::Get()`)와 타이핑 텍스트 효과(`WOT_AnimeFonts`) 신규 서브시스템은 이번 사이클에 포함하지 않는다.
   → 로고 페이드인, 튜토리얼 페이지, 종료 확인 페이지, 배경음악은 후속 사이클로 넘어간다.
3. 위젯은 렌더 스레드의 `main.cpp`가 직접 소유하는 IntroScene 사이클 패턴을 유지한다.
   → TitleScene/LoadingScene은 렌더링 코드를 갖지 않고, 씬별 위젯 세트 교체는 `main.cpp`가 맡는다.
