# Strategy: GJK + EPA (로드맵 2번)

## 적용 방식

narrow-phase 알고리즘. Geometry(variant) 두 개를 받아 (1) GJK로 충돌 여부, (2) 충돌 시 EPA로 침투 벡터(법선+깊이)를 계산한다. `Support()` 자유 함수(Geometry.h)만 사용 — `std::visit`/`std::get` 직접 호출 없음(접근 퍼사드 규칙 준수).

### 파일 구성 (`src/collision/gjk_epa/`)

- `MinkowskiSupport.h` — 헤더 온리 내부 헬퍼: `Vec3 MinkowskiSupport(const Geometry& a, const Geometry& b, const Vec3& dir)` = `Support(a,dir) - Support(b,-dir)`. GJK/EPA 둘 다 사용, 외부에 공개하지 않음.
- `Gjk.h` / `Gjk.cpp` — GJK 알고리즘. `GjkSimplex`(최대 4개 민코프스키 차 점) + `GjkResult{bool intersects; GjkSimplex simplex;}` + `GjkResult RunGjk(a, b)`.
- `Epa.h` / `Epa.cpp` — EPA 알고리즘. `PenetrationInfo{Vec3 normal; float depth;}` + `PenetrationInfo RunEpa(a, b, const GjkSimplex& startingSimplex)`.
- `GjkEpa.h` / `GjkEpa.cpp` — 공개 API(퍼사드): `bool Intersects(a,b)`, `std::optional<PenetrationInfo> ComputePenetration(a,b)`. 내부에서 `RunGjk` 실행 후 충돌이면 `RunEpa` 호출.

이렇게 3계층(Gjk/Epa/퍼사드)으로 나누는 이유: SRP — GJK는 "충돌 여부 판정", EPA는 "침투 벡터 계산"으로 책임이 다르고, EPA는 GJK의 종료 심플렉스를 입력받아 이어받는 구조라 자연스럽게 계층화된다.

### 알고리즘 개요

- **GJK**: 초기 방향은 `GetBounds(b).Center() - GetBounds(a).Center()`(0이면 (1,0,0) 대체) → 민코프스키 차 점을 반복 추가하며 원점을 감싸는 사면체(4점)를 찾는 표준 Voronoi-region 기반 GJK(점→선→삼각형→사면체 케이스 처리). 매 반복 `Dot(newPoint, direction) < 0`이면 분리축 발견 → 비충돌 조기 종료.
- **EPA**: GJK가 반환한 사면체를 다면체(폴리토프) 초기값으로, 원점에서 가장 가까운 면을 찾아 그 법선 방향으로 새 지지점을 추가 → 그 지지점이 보이는 면들을 제거하고 지평선(horizon) 엣지로 새 면을 재구성 → 개선폭이 임계값 이하로 수렴하면 그 면의 법선·거리를 반환.
- 반복 횟수 상한(예: 64)을 두어 무한루프 방지.

### 테스트 전략

두 Sphere로 (1) 완전 분리, (2) 표면 접촉 근처, (3) 침투(EPA 깊이가 반지름 합 - 중심거리의 해석적 값과 근접) 케이스를 우선 검증 — 해석적 정답이 있어 GJK/EPA 정확성 검증에 가장 안전하다. 이후 AABB/OBB/Capsule/Cylinder/Mesh 조합 몇 개를 추가로 검증(각각 최소 1개 충돌/비충돌 케이스).

## 구현 중 발견한 이슈 및 대응 (참고 기록)

- 축 정렬된 대칭 배치(예: 두 구가 한 축 위에 정확히 나란함)에서 GJK 초기 탐색 방향이 도형의 대칭축과 정확히 일치하면, 심플렉스 점들이 정확한 대척점 쌍이 되어 EPA에서 원점이 여러 면의 평면 위에 정확히 걸치는 퇴화 케이스가 반복 발생 — 초기 탐색 방향에 작은 고정 지터(`RunGjk`)를 더해 해결.
- AABB/OBB처럼 지지 함수가 한 옥탄트 전체에서 같은 점(모서리)을 반환하는 도형은, 가장 가까운 면의 법선으로 재탐색해도 그 면 자신의 정점과 같은 점이 나와 거짓 수렴이 발생 — 지지점이 기존 정점과 중복이면 다음으로 가까운 면으로 넘어가도록 `RunEpa`에 보정 로직 추가.
- 두 대응 모두 `tests/GjkEpaTest.cpp`의 해석적 깊이 비교 테스트로 회귀 방지.
