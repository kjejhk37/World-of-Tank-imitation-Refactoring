# Strategy: 원본 리소스 이식

## 목적

브레인스토밍에서 확정한 새 폴더 구조로 원본 WOT 리소스를 옮겨 비공개 `WOT-assets` 저장소에 커밋하고, 공개 코드 저장소에 `assets/` submodule로 연결한다.
원본 경로 → 새 경로 대응표(`manifest.csv`)를 함께 남겨, 이후 로더 리팩토링의 기준으로 삼는다.

Cross-repo 의존성 검토: `platform`/`graphics`는 변경이 없다.
`WOT-assets`는 Team Task Delegation 체인(`platform → graphics → projects`)에 속한 저장소가 아니라 이 사이클에서 새로 만드는 리소스 보관 저장소이며, 사용자가 로컬 저장소를 이미 만들었다.
따라서 전 항목이 `[self]`다.

이번 사이클에는 C++ 코드와 CMake 변경이 없다.

이름 변환 규칙 (브레인스토밍 결정 사항의 폴더 구조·이름 규칙을 파일 단위로 적용한 것):

- `PascalCase`/`camelCase`를 소문자 snake_case로 바꾼다 — `AtticFloor` → `attic_floor`, `skyBox` → `sky_box`, `AITankFound` → `ai_tank_found`.
- 글자 뒤에 붙은 숫자는 `_`로 떼고 한 자리 숫자는 두 자리로 맞춘다 — `Tank01` → `tank_01`, `bark1` → `bark_01`, `trail0` → `trail_00`.
- 텍스처 맵 약어를 단어로 바꿔 이름 끝에 둔다 — `_DM` → `_diffuse`, `_NM` → `_normal`, `_SM` → `_specular`. 괄호 번호는 맵 이름 앞에 둔다 — `Trims_DM (2).png` → `trims_02_diffuse.png`.
- 같은 폴더에 번호 붙은 형제 파일이 있으면 번호 없는 파일에 `_01`을 붙인다 — `Grass_DM` + `Grass02_DM` → `grass_01_diffuse` + `grass_02_diffuse`.
- Blender 자동 번호(`.001`)는 지운다. 지우면 같은 폴더 파일과 이름이 겹치는 경우만 `_001`로 남긴다 — `Tank01_Turret/Material_0.001.mat` → `material_00_001.mat` (같은 폴더에 `Material_0.mat` → `material_00.mat`이 있음).
- 원본 파일명 오타를 고친다 — `Fance.wav` → `fence.wav`, `Rock_Fance.wav` → `rock_fence.wav`.
- 폴더 이름에서 뜻이 드러나는 접미사는 뺀다 — `UI/bg/title_bg.png` → `ui/backgrounds/title.png`, `UI/Tank01_Icon.png` → `ui/icons/tanks/tank_01.png`, `TextData/Tables/Bush01Table.csv` → `data/placement/battle/bush_01.csv`, `SelectScene_Bush01Table.csv` → `data/placement/select/bush_01.csv`, `Models/LandscapeMaps/Terrain01_HeightMap.png` → `terrain/maps/battle_01/battle_01_height_map.png`.

대응표 `notes` 열에 기록되는 주의 사항:

- `.mats` 22개: 파일 내부에 원본 경로(`Models/Materials/Tank01_Body/Material01.mat` 등) 포함.
- `.mat` 86개: 파일 내부에 원본 머티리얼 이름(`Material01`, `roof_tall` 등) 포함.
- `.map` 2개: 파일 내부에 원본 경로(`Models\LandscapeMaps\Terrain01_HeightMap.png`, `Textures\Landscape\Soil_DM.png` 등) 포함.
- 내용 완전 중복 4쌍: `attic_floor_diffuse.png` = `floors_planks_diffuse.png`, `tank_01_caterpillar_{diffuse,normal,specular}.png` = `tank_03_caterpillar_{diffuse,normal,specular}.png`.
- 원본 코드·파일 내용은 수정하지 않으므로, 위 내부 경로·이름은 새 구조와 어긋난 채 보관된다.
