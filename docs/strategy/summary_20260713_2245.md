# How

브레인스토밍에서 확정된 내용을 다음과 같이 코드/파일로 적용한다.

1. `src/` 디렉토리를 만들고, 그 안에 `main.cpp`를 작성한다. 내용은 로직 없이 `int main() { return 0; }`만 둔다 (wWinMain이 아닌 int main 확정, 순수 스텁 범위 확정에 따름).
2. 최상위에 `CMakeLists.txt`를 작성한다.
   - `cmake_minimum_required(VERSION 3.20)`
   - `project(WorldOfTankImitationRefactoring LANGUAGES CXX)`
   - `set(CMAKE_CXX_STANDARD 17)`, `set(CMAKE_CXX_STANDARD_REQUIRED ON)` (C++17 확정에 따름)
   - `add_executable(main src/main.cpp)` — 타겟 이름을 `main`으로 지정해 `main.exe`가 그대로 생성되도록 한다.
3. Ninja generator로 configure한다: `cmake -B build -G Ninja`.
4. 빌드한다: `cmake --build build`.
5. 빌드 산출물 `build/main.exe`를 직접 실행해서 정상 종료(exit code 0)를 확인한다.

디렉토리 구조 외의 것(창 생성, DirectX/OpenGL 초기화, 전체 프로젝트 구조 설계)은 이번 범위에 포함하지 않는다.

# Verification Criteria (완료 기준)

- `cmake -B build -G Ninja` 명령이 에러 없이 성공한다.
- `cmake --build build` 명령이 에러 없이 성공하고, `build/main.exe`가 생성된다.
- `build/main.exe` 실행 시 exit code가 0이다.
- 단위 테스트는 작성하지 않는다 (브레인스토밍에서 합의된 예외 — 로직이 없는 스텁이라 테스트 대상이 없음).
