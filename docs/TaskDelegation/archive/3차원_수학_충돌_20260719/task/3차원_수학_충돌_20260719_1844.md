# Task: 기초 3차원 수학/충돌 데이터 클래스

## Purpose

기초적인 3차원 연산을 위한 데이터 클래스(`Vec3`, `AABB`, `OBB`, `Sphere`, `Capsule`, `Cylinder`, `Mesh`)를 정의하고,
`Vec3` 기반의 기본 연산과 각 도형 간의 충돌/포함 판정 로직을 구현한다.

## Author

(비워둠)

## User Draft

- 데이터 클래스: `Vec3`, `AABB`, `OBB`, `Sphere`, `Capsule`, `Cylinder`, `Mesh`
- `Vec3` 연산: 덧셈, 뺄셈, 곱셈, 나눗셈, 외적, 내적, 길이(length) 등
- `AABB`/`OBB` 기반 point 포함 여부 판정
- `AABB` 간의 충돌 여부 판정, 공통 공간(겹치는 영역) 추리기
- `OBB`/`AABB`/`Capsule`/`Sphere`/`Cylinder` 사이의 충돌 감지 로직
- `Mesh` 기반 충돌 검사는 이번 사이클 범위에서 제외 — 더 복잡해서 별도 방법으로 진행 예정. `Mesh` 데이터 클래스 자체(정점/인덱스 등 표현)는 이번 사이클에 포함.
