# Notes

- `LaunchConfigStore`는 namespace 기반 전역 저장소이며 "부팅 시 1회 초기화 후 불변" 계약을 가정함 — 이후 런타임 가변 설정이 추가될 경우 이 계약을 재검토해야 함(브레인스토밍에서 Unreal `GConfig` 사례 참고해 논의됨).
- config.json 도입 여부는 이번 사이클 범위에서 의도적으로 제외 — 브레인스토밍에서 "한 태스크는 한 목적" 원칙에 따라 별도 태스크로 미루기로 합의됨. 도입 시 `AppConfig`/`AppConfigStore`(현 `LaunchConfig`/`LaunchConfigStore`) 하위 코드는 거의 수정 없이, 새 파싱 함수 + `main()` 조립 로직 몇 줄만 추가되는 구조로 설계해둠.
