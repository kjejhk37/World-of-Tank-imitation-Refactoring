## 전략서와 다르게 된 점

- `WOT-assets/README.md`에 승인안 본문 외에 `manifest.csv` 열 설명 표와, 문서 규칙상 필수인 `요약` / `사용자 결정 사항` / `사용자 확인 사항` 섹션을 추가했다.
- `manifest.csv`는 Python `csv` 모듈 기본값으로 CRLF 줄바꿈으로 저장되었다. 리소스 CSV는 원본 그대로 LF다. `* -text` 설정이라 커밋된 바이트는 작성한 그대로다.
