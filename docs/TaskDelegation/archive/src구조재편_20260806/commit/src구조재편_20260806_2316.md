# 구현 결과: src 구조 재편 (app → projects, platform/graphics 분리)

## 요약

전략 문서의 33개 체크리스트 항목을 전부 완료했다.

- `src/app` → `src/projects`, `src/config` → `src/projects/config`로 이름 변경.
- `math/collision/entity_component/geometry/logging/serialization/model_import`와 engine·persistence의 범용 부분(`DoubleBufferPublisher`/`IFrameDataPublisher`, `ISaveable`/`SaveLoadManager`)을 `src/platform`으로 이동.
- `renderer/ui`와 engine의 렌더러 계약 타입(`InstanceSnapshot`)을 `src/graphics`로 이동.
- WOT 전용 콘텐츠(`InstanceUpdateWorker`, `PlayerProgress`)는 `src/projects`에 유지.
- `RendererFactory::Create(LaunchConfig&)` → `RendererFactory::Create(RendererBackend)`로 시그니처를 좁혀 graphics→projects 순환 의존 제거.
- `CMakeLists.txt`를 `platform_lib`/`graphics_lib`/`app_lib` 3개 타겟으로 분리, `platform_lib`는 어떤 상위 타겟도 링크하지 않도록 강제.
- `docs/architecture/platform_graphics_projects.md` 신설(영구 보관, archive 대상 제외).
- 코드 리뷰(`docs/review/src구조재편_20260806_2315.md`)에서 발견된 4건(철학 위반 2건 + 문서 경로 stale 2건)을 전부 즉시 해소.
