# Task: src 구조 재편 (app → projects, platform/graphics 분리)

## Purpose

`src` 내부 폴더 구조를 재편한다.
기능적으로 어느 정도 완성된 시점이므로, 최소 단위 기능 모음을 분리해 재사용성을 높이고 향후 submodule화를 준비한다.

## Author

## User Draft

- 기능이 많이 만들어졌으므로 지금 시점에 src 내부 코드 일부를 분리하고, 재사용성을 위해 submodule화까지 진행하고자 함.
- 최종적으로 다음과 같은 3분할 구조를 목표로 함.
  - `src/projects` — 현재 프로젝트(WOT)를 구현하기 위한 platform + graphics + 프로젝트 전용 구현 구간.
  - `src/platform` (가칭, submodule) — 최소 단위 기능을 모은 검증된 개인 라이브러리.
  - `src/graphics` (가칭, submodule) — DirectX, OpenGL 등 그래픽스 기능 라인.

## Requirements

1. `src/app` 폴더명을 `src/projects`로 변경.
2. `app` 이외의 최소 단위 기능 모음(collision, entity_component, math, logging 등)을 `platform` 폴더 안으로 정리.

## 확인 요청 사항 (Claude 검토 필요)

- DirectX, OpenGL과 같이 "최소 단위 기능"이 아닌 엔진 내 그래픽스 관련 부분을 별도로 모아 `graphics`로 platform화하는 것이 타당한지 검토 요청.
- (Claude 조사) 현재 `src/platform`에 이미 `Win32Window.h/.cpp`가 존재 — 요구사항 2의 "platform" 명칭과 충돌 여부 검토 필요. Step 2 브레인스토밍에서 다룸.
