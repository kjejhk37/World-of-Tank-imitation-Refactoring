# Task: 에러/로그 매니저 (Error Message Manager)

## Purpose

현재 `try/catch`에서 에러 발생 시 강제 종료로만 처리하고 있고, 이에 대한 Error Code 등 체계가 규정되어 있지 않다.
로그 등급을 나누어 기록하고, 이를 콘솔 및 파일로 내보내는 기본적인 로그 시스템(에러 메시지 매니저)을 만든다.

## Author

(비워둠)

## User Draft

- 로그 등급을 `Error`/`Warning`/`Info` 3단계로 나눈다.
- 로그 포맷: `로그 타입 : 로그 시간 : 내용`.
- cmd 창이 있으면(콘솔이 연결된 경우) 콘솔에도 출력한다.
- 마지막 로그는 지정된 경로로 `.txt` 파일로 내보낸다.
  - 경로가 지정되지 않으면 파일로는 내보내지 않는다(콘솔 출력만 유지).
- 그 외 기본적인 로그 시스템에 필요한 요소는 Claude가 브레인스토밍 단계에서 제안한다.

## Requirements

1. 로그 등급: `Error`, `Warning`, `Info` — 등급별 출력 여부/포맷 규정.
2. 로그 포맷: `타입 : 시간 : 내용` — 콘솔이 연결되어 있으면 그 자리에서 출력.
3. 파일 출력: 지정 경로가 있을 때만 `.txt`로 로그를 내보냄. 미지정 시 파일 출력 생략.
4. (브레인스토밍에서 확정) 기존 `try/catch` 강제 종료 처리와의 연동 방식, Error Code 체계 도입 여부, 로그 대상(어느 예외/이벤트를 로깅할지) 범위.
