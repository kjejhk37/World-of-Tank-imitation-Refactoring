- 구현 중 콘솔 출력 조건을 최초안(`GetConsoleWindow() != NULL`)에서 `GetStdHandle(STD_OUTPUT_HANDLE/STD_ERROR_HANDLE)` 핸들 유효성 검사로 변경했다 — `GetConsoleWindow()` 방식은 출력이 리다이렉트/캡처되는 환경(ctest 등)에서 콘솔 창이 없다는 이유로 정상 리다이렉트 출력까지 막아버리는 문제가 테스트로 발견되어 대체함. 콘솔 직결/리다이렉트 모두 정상 기록되고, 핸들 자체가 없는 경우(WIN32 서브시스템 등)만 조용히 생략된다.
- Error Code는 이번 사이클에서 확인된 4개 지점(`main.cpp`)만 다루며, 카테고리별 번호 대역(1000/2000/3000)으로 설계해 향후 항목·카테고리 확장 시 기존 번호가 밀리지 않도록 여지를 남겨뒀다. 다음 카테고리는 4000번대부터 배정.
- 로그 파일 핸들은 `Log::Init`이 구성한 `g_logger`(프로세스 전역, static 수명)가 계속 들고 있으므로 프로세스 종료 전까지 열려 있다 — 이는 실시간 저장을 위한 의도된 설계이며, 이 파일을 앱 실행 중에 외부에서 삭제/이동하려 하면 Windows에서 거부될 수 있음(운영 시 참고).
