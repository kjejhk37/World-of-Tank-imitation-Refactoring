# Notes

- DX9의 `D3DDEVTYPE_NULLREF` 테스트는 레거시 DirectX SDK 컴포넌트 의존성 때문에 `D3DDEVTYPE_HAL`로 대체 검증 — 이 개발 환경의 실제 GPU/드라이버 기준으로 통과 확인. 레거시 SDK가 없는 CI 환경으로 이전할 경우 이 테스트의 재검토가 필요할 수 있음.
- DX11/DX12는 `forceWarp` 테스트 전용 생성자 파라미터로 GPU 유무와 무관하게 결정적으로 검증 가능 — production 경로는 하드웨어 우선 시도 후 실패 시 WARP 자동 폴백.
- `kFrameCount`는 계획 단계의 단일 상수에서 `kBackBufferCount`(스왑체인 버퍼 수)와 `kCommandListCount`(커맨드 리스트 수)로 구체화 — DX12 멀티스레드 기록 확장 시 이 두 상수를 기준점으로 삼을 것.
- 실제 draw call(geometry, 셰이더 파이프라인 등)은 이번 사이클 범위 밖 — 다음 사이클 대상.
