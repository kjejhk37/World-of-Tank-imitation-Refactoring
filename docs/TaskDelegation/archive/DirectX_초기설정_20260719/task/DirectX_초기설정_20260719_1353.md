# Task: DirectX 초기 설정 및 빈 화면 출력

## Purpose

기본적인 DirectX 초기화(디바이스/스왑체인 등)를 세팅하고, 아무것도 그리지 않는 빈 화면(윈도우)을 띄운다.
가능하면 DirectX 버전을 선택할 수 있게 한다.

## Author

(비워둠)

## User Draft

- 기존 `src/renderer/DirectXRenderer.h/.cpp`가 스텁 상태(`Initialize()`가 미구현 값만 반환)이며, 이 사이클에서 실제 초기화 로직으로 채울 예정.
- "DirectX 버전 선택" 확정: DirectX 11과 DirectX 12를 **둘 다 실제로 구현**하고, 외부 Config(`config.json`/`ConfigManager`)에서 읽은 값에 따라 런타임에 어느 버전을 실행할지 결정한다.
  - 이유: (1) 사용자 GPU/드라이버 환경별 호환성 대응, (2) 포트폴리오 관점에서 DX12 개발 역량도 보여줄 필요.
  - 래핑 원칙: `nlohmann::json`을 `JsonDataStore` 내부로 격리한 것과 동일 — DX11/DX12 각각의 API 호출은 각 wrapper 클래스 내부에만 존재하고, 외부(호출부)는 안정된 인터페이스(`IRenderer` 등)와 버전 선택값만 알면 되는 구조.
- 코드베이스에 아직 Win32 윈도우(HWND) 생성 코드가 없음 — "빈 화면을 띄운다"는 요구를 만족하려면 이번 사이클에 윈도우 생성도 포함되어야 하며, 이 역시 별도 wrapper로 분리할지 브레인스토밍에서 논의 필요.
