# Strategy: 통일 Geometry 입력 타입 (충돌 감지 알고리즘 로드맵 1번)

## 적용 방식

브레인스토밍 최종 결론(변경 없음, 재확인만): (B) `std::variant` 기반 통일 타입을 채택하고, Geometry 모듈 밖에서는 `std::visit`/`std::get`을 직접 쓰지 않고 자유 함수(`Support()`/`GetBounds()`)로만 접근한다. 이 규칙은 코드로 강제되지 않고 컨벤션(코드 리뷰 대상)이다 — `Support`/`GetBounds` 선언부만 공개 API로 간주한다.

### 파일 구성

- `src/geometry/Geometry.h` — 타입 별칭 + 자유 함수 선언 (기존 `Intersections.h`와 동일하게 선언/구현 분리)
- `src/geometry/Geometry.cpp` — `Overload` 헬퍼 + `std::visit` 기반 구현
- `tests/GeometryTest.cpp` — 6개 도형 각각에 대한 `Support()`/`GetBounds()` 단위 테스트

```cpp
// Geometry.h (핵심부만 발췌)
#include <variant>
#include "geometry/AABB.h"
#include "geometry/Capsule.h"
#include "geometry/Cylinder.h"
#include "geometry/Mesh.h"
#include "geometry/OBB.h"
#include "geometry/Sphere.h"
#include "math/Vec3.h"

using Geometry = std::variant<Sphere, AABB, OBB, Capsule, Cylinder, Mesh>;

Vec3 Support(const Geometry& geometry, const Vec3& direction);
AABB GetBounds(const Geometry& geometry);
```

```cpp
// Geometry.cpp (핵심부만 발췌)
template <class... Ts>
struct Overload : Ts...
{
    using Ts::operator()...;
};
template <class... Ts>
Overload(Ts...) -> Overload<Ts...>;

Vec3 Support(const Geometry& geometry, const Vec3& direction)
{
    return std::visit(Overload{
        [&](const Sphere& s) { return s.center + direction.Normalized() * s.radius; },
        [&](const AABB& b) { /* 각 축마다 direction 부호에 따라 min/max 선택 */ },
        [&](const OBB& b) { /* 로컬 축 3개에 대해 dot(direction, axis) 부호로 halfExtent 가감 */ },
        [&](const Capsule& c) { /* pointA/pointB 중 direction과 내적이 큰 쪽 + radius*direction.Normalized() */ },
        [&](const Cylinder& c) { /* 축 방향 성분으로 캡(A/B) 선택 + 축 수직 성분 방향으로 radius만큼 확장 */ },
        [&](const Mesh& m) { /* 모든 vertex 중 dot(direction, vertex) 최대인 점 */ },
    }, geometry);
}

AABB GetBounds(const Geometry& geometry)
{
    return std::visit(Overload{
        [&](const Sphere& s) { return AABB(s.center - Vec3(s.radius,s.radius,s.radius), s.center + Vec3(s.radius,s.radius,s.radius)); },
        [&](const AABB& b) { return b; },
        [&](const OBB& b) { /* 표준 OBB→AABB 변환: 월드축 j에 대해 extent_j = sum_i |axis_i . e_j| * halfExtent_i */ },
        [&](const Capsule& c) { /* pointA/pointB 각각 ± radius로 감싸는 AABB의 합집합 */ },
        [&](const Cylinder& c) { /* Capsule과 동일 방식(캡이 평평해도 안전한 근사, 타이트하지 않아도 broad-phase 용도로 충분) */ },
        [&](const Mesh& m) { /* 모든 vertex의 min/max */ },
    }, geometry);
}
```

Mesh의 `Support`/`GetBounds`는 정점을 O(n) 순회한다 — 이번 사이클은 정확성 우선이며, 가속(BVH 등)은 이후 로드맵 항목에서 별도로 다룬다.
