# Task: WOT-master 게임 로직 레이어 이식 (GameManager/Objects/Scene/Algorithm)

## Purpose

WOT-master(`D3DX_2209`)에는 있지만 현재 리팩토링 프로젝트(`src/`)에는 아직 이식되지 않은 게임 오브젝트/씬/게임 루프 레이어를 옮긴다.
지금까지는 렌더러, 충돌 검사, 수학, 모델 임포터, 로깅, 설정 저장/로드 등 엔진 인프라(`src/platform`, `src/graphics`)만 리팩토링되었고, 그 위에서 실행되는 실제 게임 로직은 아직 원본(WOT-master)에만 존재한다.
이번 사이클의 목표는 그 게임 로직 레이어를 리팩토링된 인프라 위로 이식하는 것이다.

## User Draft

- 사용자 지시: "WOT에 대해서야 현재 WOT-master를 기준으로 필요한 기능들을 옮겨줘."
- Claude 조사 결과, WOT-master에만 존재하고 리팩토링 프로젝트에는 없는 4개 영역을 식별함.
  - `GameManager/` — GameManager, SceneManager (게임 루프, 씬 전환)
  - `Objects/` — Basic, Character, Landscape, Manager, Particle, PostEffect, UI (게임 오브젝트 계층)
  - `Scene/` — 다수의 데모/튜토리얼 씬 + `Scene/WOT/`(SkyScene, TestScene, WOT.cpp/h — 실제 전차전 게임 로직)
  - `Algorith/` — AStar, Heap, Node, Observer (경로탐색 알고리즘)
