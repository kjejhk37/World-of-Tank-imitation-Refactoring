## Stage 1 — Quality Inspection

독립성(모든 모듈 간 cross-include를 grep으로 확인 — `Fcl`이 `Bvh`/`GjkEpa`를 참조하는 것 외에는 전부 깨끗함), 주석 규칙(전 파일 Author/설명/Input/Output/Notes/Date 헤더 확인), 라이브러리 격리(외부 라이브러리 없음), 단위 테스트(전 모듈 겹침/비겹침 최소 커버리지 + 해석적 값 비교) 전부 이상 없음.

- [RESOLVED] `ConservativeAdvancement.cpp` — 반복 상한(32회) 도달 시 실제 수렴 확인 없이 무조건 충돌로 간주하던 문제.
  - **[해결 방안]** GJK의 비수렴 기본값(false)과 일관되게 `ToiResult{false, deltaTime}`으로 변경 완료. 재빌드 + `ConservativeAdvancementTest` 4개 재확인.
- [RESOLVED] `Gjk.cpp` — 초기 탐색 방향 지터 값 `Vec3(0.3f, 0.4f, 0.35f)`이 이름 없는 매직 넘버였던 문제.
  - **[해결 방안]** `const Vec3 kInitialDirectionJitter(...)`로 이름 붙이고 "임의로 바꾸면 안 되는 값" 의도를 주석에 명시. 재빌드 + `GjkEpaTest` 13개 재확인.
- [RESOLVED] `VoxelGrid.cpp` — worldBounds 밖 좌표를 경계 셀로 clamp하는 로직이 테스트로 검증되지 않던 문제.
  - **[해결 방안]** `VoxelGridTest.cpp`에 두 객체가 clamp로 같은 셀에 묶여도 실제로는 안 겹치는 케이스 추가, 통과 확인.
- [RESOLVED] `Mpr.h` — OBB 등 평평한 도형에서 포탈 정제가 수렴하지 않는 한계가 commit 문서에만 기록되고 헤더에는 없던 문제.
  - **[해결 방안]** `Mpr.h` Notes에 이 한계를 한 줄 추가.

수정 후 전체 테스트 재실행: 227개 중 226개 통과(유일한 실패 `Win32WindowTest.PumpMessagesReturnsTrueWhenNoQuitPosted`는 이번 사이클과 무관한 기존 이슈, 각 commit 문서에 이미 기록됨).
