# Task: 충돌 감지 알고리즘 라이브러리 구현

## Purpose

모듈 내 라이브러리 형태로 충돌 감지(Collision Detection) 알고리즘을 구현한다.
아래 5종 알고리즘을 각각 독립된 모듈로 구현하고, 이 외에 추가로 도입할 만한 알고리즘이 있는지 브레인스토밍을 진행한다.

## Author

(미기재)

## User Draft

1. GJK(Gilbert-Johnson-Keerthi) 및 EPA(Expanding Polytope Algorithm) 구현
2. BVH(Bounding Volume Hierarchy) 구현
3. R-Tree 구현
4. Voxel 공간 구현
5. FCL(Flexible Collision Library) 구현

이 외 Claude가 추천하는 다른 충돌 감지 알고리즘이 있는지 브레인스토밍 진행.

## Requirements

1. 각 알고리즘 모듈은 서로 독립적이어야 한다. (한 알고리즘이 다른 알고리즘 모듈에 의존하지 않는다.)
2. 각 알고리즘의 input 데이터는 `src/geometry` 및 `src/math`에 정의된 타입만 사용하여 구현한다.
3. 외부 라이브러리를 사용할 경우, 기존 정책(`agent_harness/CLAUDE.md` — 외부 라이브러리 래핑 원칙)에 따라 특정 스크립트에서만 해당 외부 라이브러리를 알 수 있도록 관리한다.
