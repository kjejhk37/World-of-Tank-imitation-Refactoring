# Task: Config 및 Save/Load 시스템 초안

## Purpose

Config 데이터와 게임 진행(Save/Load) 데이터를 저장하고 다시 불러오는 시스템의 설계 초안을 작성한다.

- Config: `.json` 또는 DB 데이터를 사용해 `main` 시작 시 특정 데이터를 읽어, 여러 설정 값을 세팅할 수 있게 한다.
- Save/Load: `main` 실행 중 발생하는 데이터를 저장하고 불러오는 시스템을 미리 만들어 둔다.

## User Draft

- Config와 Save/Load는 원래 별도 Task로 진행해도 무방하다고 판단했으나, 두 시스템 모두 "영속 데이터 입출력"이라는 공통 성격을 가지므로 하나의 Task로 통합해 진행한다.
  - 사용자 의견: Config가 Save/Load 시스템 안에 충분히 녹아들 수 있지 않을까 하는 개인적인 판단.
  - 다만 SRP(단일 책임 원칙) 준수를 위해, 통합 진행하더라도 Config와 Save/Load는 브레인스토밍 단계에서 책임 단위(클래스/모듈)를 명확히 분리해서 설계할 것.
- 이번 사이클에서 프로젝트의 기본 아키텍처도 함께 정리하기로 함 (`docs/project_initial_setup.md` 참고).
