- **[DEFERRED]** `Mesh` 기반 충돌 검사 — 데이터 표현(`Mesh.h`)만 이번 사이클에 포함, 실제 충돌 로직은 더 복잡한 별도 방법(BVH 등)으로 다음 사이클에서 진행 예정.
- 이번 사이클의 쌍별 특수 함수(`Intersections.cpp`)는 사용자의 최종 그림(BVH/FCL 기반 시스템 위에 성능 최적화용 빠른 경로로 얹는 것)의 첫 단계다 — GJK/BVH/FCL은 손으로 구현하지 않고 향후 외부 라이브러리 도입 대상으로 남겨둠.
- ImGui v1.92.8의 `ImGui_ImplDX12_Init` API 변경 사례처럼, 이번 사이클에서도 계획 당시 가정("Capsule-AABB/OBB는 선분-박스 닫힌 형태 공식")과 실제 구현(alternating-projection 반복 기법)이 달라진 지점이 있었음 — 코드 리뷰에서 반복 횟수 근거와 브루트포스 대조 테스트로 신뢰성을 보강함.
- `src/math`/`src/geometry`는 프로젝트의 다른 모듈을 전혀 참조하지 않는 상태를 유지 중 — 사용자가 "안정화되면 별도 저장소로 뽑아 submodule화"하겠다고 밝힌 계획의 전제 조건이 계속 충족되고 있음.
